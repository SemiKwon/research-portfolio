대표 프레임 선택과 시간 관계 학습

BLIP-2는 각 프레임을 중첩된 시퀀스로 처리하기 때문에, 영상의 연속성과 장면 전환을 반영하는 방식을 채택했습니다.

  • 프레임 특징을 코사인 유사도 기준으로 16개 구간에 군집화(Dynamic Programming Clustering)하고, 군집 중심점을 대표 프레임으로 선택 → 동일한 16프레임에서 정보량 증가
  • BLIP-2 비전 인코더 뒤에 프레임 간 어텐션(temporal attention) 모듈을 삽입해 시간적 연속성과 장면 전환 정보 학습

3.1<산학> VideoLLaMA 2 기반 파이프라인과 구간 분할

기준에 대한 의견 차이

하이라이트 판단 기준이 화면 구성(클로즈업)과 음향 고조로 나뉘어, 한쪽 기준만으로는 근거 있는 합의 도출이 어려움

모달리티 제약

기존 파이프라인은 영상과 텍스트만 처리해 음향 기준을 점수로 반영 불가 → 오디오까지 다루는 모델 교체와 파이프라인 재구성 필요

시간 맥락 편중

3분 영상을 한 번에 입력하면 후보가 앞부분에 편중 — 사전학습 데이터가 1분 내외인 점이 원인으로 추정

해결

  • 사전학습 데이터 길이에 맞춰 3분 영상을 3개 구간으로 분할, 구간별로 VLM 분석 → 앞부분 편중 완화
  • 구간별 후보를 원본 타임스탬프로 역변환 · 통합해 영상 전체의 장면 커버리지 확보
  • 하이라이트 자동 생성 파이프라인 설계 및 구축
한계 의미적 주요 장면 탐지는 효과적이나, 추출 구간이 경계에 걸리면 맥락을 포괄하지 못하는 장면 맥락 파편화 발견

3.2<개인> 다중 신호 융합 기반 E2E 프로토타입

후보 장면이 구간 경계에 걸리면 맥락이 단절되고, VLM은 의미적 중요도는 파악하지만 실제 편집에 필요한 문맥이 보존된 정밀한 장면 추정에는 한계가 있었습니다.

A · SIGNAL LAYER
실제 peak 위치를 초 단위로 탐지

Audio RMS, 얼굴 검출(신뢰도 × 화면 점유율), Optical Flow Motion Score를 1초 단위로 분석

B · SEMANTIC LAYER
의미적으로 중요한 장면 제안

Overlapping Window로 의미적으로 중요한 장면의 후보 위치와 신뢰도 산출

C · FUSION
의미와 편집점이 명확한 장면 탐지

VLM 후보 주변에 신뢰도 기반 Gaussian Bonus를 부여하고 Signal Score와 결합

후처리

  • 영상별 점수 분포에서 임계값을 산출해 하이라이트 후보 추출
  • 상위 구간을 목표 길이에 맞추고 시간순으로 결합해 최종 영상 생성

3.3E2E 시스템 구현

FastAPI

영상과 분석 옵션을 입력받고, 장시간 추론을 비동기 작업으로 등록한 뒤 Polling API로 진행 상태와 결과 제공

LangGraph

7개 노드의 Stateful Workflow로 구간별 VLM 분석, 조건부 반복, 결과 병합 과정을 제어하고 중간 상태 관리

React Dashboard

목표 길이 · 신호 가중치 · 분석 구간 · 프롬프트를 입력받고 점수 변화 · 후보 구간 · 최종 영상과 메타데이터 통합 확인
